# Quick Spec - GPT 5.x 模型切换（QS）

## 1. 背景
- 当前系统前后端默认与可选 GPT 模型仍包含 `gpt-4o / gpt-4o-mini`。
- 目标是统一升级为 `gpt-5.3 / gpt-5.4`，并保证设置页、聊天页、检索 API、用例生成入口、观测统计口径一致。

## 2. 目标
- 所有用户可见 GPT 选项替换为 `GPT-5.3` 与 `GPT-5.4`。
- 后端白名单与默认值同步更新，避免“前端可选但后端拒绝”。
- 关键测试通过，确保无回归。

## 3. 范围
- 包含：
- AI 设置页模型选项与默认值
- Dashboard 聊天页模型选项与默认值
- `/api/settings/ai` 模型白名单与默认值
- `/api/knowledge/search` 模型白名单与默认值
- AI 用例生成页面模型候选
- Langfuse 模型成本映射键名
- 对应单测数据更新

- 不包含：
- 新增第三方模型供应商接入
- 变更模型价格真实计费策略（仅键名迁移）

## 4. 验收标准
- AI 设置页只展示 `GPT-5.3 / GPT-5.4 / Claude 3.7 Sonnet / Kimi K2.5`。
- Dashboard 发送请求时 `model` 字段可为 `gpt-5.3` 或 `gpt-5.4` 并被 API 接收。
- `/api/settings/ai` 保存 `gpt-5.3` 与 `gpt-5.4` 均成功。
- `/api/knowledge/search` 请求 `model=gpt-5.3|gpt-5.4` 不触发校验错误。
- 相关测试全部通过。

## 5. 风险与回退
- 风险：若外部模型网关不支持新模型名，运行时可能回退到非 API 模式。
- 缓解：保留现有 fallback 机制并在响应 `modelRuntime` 里可见状态。
- 回退：仅需将模型枚举与默认值恢复到旧版本并重跑测试。

## 6. 实施清单（给 QD）
1. 更新前端模型枚举与默认值。
2. 更新 API 白名单与默认值。
3. 更新 observability 成本映射键名。
4. 同步更新相关测试 mock。
5. 运行目标测试集并记录结果。

- 状态：已完成（与本次改动一致）
