## 运行测试

```bash
# 进入项目目录
cd ai-test-platform/my-app

# 安装依赖
npm install

# 运行所有 E2E 测试
npm run test:e2e

# 运行特定测试文件
npx playwright test e2e/dashboard.spec.ts

# 运行 Smoke 测试
npx playwright test --grep "@smoke"

# 运行 UI 模式
npm run test:e2e:ui

# 调试模式
npm run test:e2e:debug
```

## 测试特点

1. **认证 Fixture**: 使用 `auth.setup.ts` 提供已登录页面 fixture
2. **语义化定位**: 使用文本、角色等语义化选择器
3. **响应式测试**: 包含移动端视口测试
4. **Smoke 测试**: 核心功能标记 @smoke 标签
5. **P0/P1 分级**: 按优先级分组测试
