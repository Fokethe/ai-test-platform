# 2-3 页粗模板预览

## 使用方式

- 先收集足够支撑 5-10 页的信息池
- 再把信息池压缩成 2-3 页专题
- 这个预览只用于方向确认，不是最终文案

## 默认 2 页方案

### Page 1：能力定位

- section title:
- one-line service proposition:
- capability card 1:
- capability card 2:
- capability card 3:
- optional capability card 4:
- proof area:

### Page 2：服务范围与交付

- section title:
- scope group or matrix:
- process / delivery steps:
- application scenarios:
- standards / deliverables:

## 可选第 3 页

### Page 3：资质证明与案例

- section title:
- certificate highlights:
- report proof:
- case highlights:
- value summary:

## 可替换字段

- company name
- service line
- audience angle
- industry / region
- client scenario
- proof / qualifications
- cases

## 可调参数

- final page count: `2 / 3`
- emphasis order
- card quantity
- card density
- formal vs proposal tone
- keep / redesign boundaries
