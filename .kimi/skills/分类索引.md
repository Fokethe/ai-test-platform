## 快速选择指南

### 决策树：我需要哪个 Skill？

```
Q1: 你在项目的哪个阶段？
│
├─ 📋 项目启动阶段
│  ├─ 需求不明确 → Skill 5 (需求审问)
│  └─ 开始新项目 → Skill 0 → 1 → 5 → 3
│
├─ 🚀 开发实施阶段
│  ├─ 需要做计划 → Skill 3 (任务规划)
│  ├─ 并行处理多任务 → Skill 10 (多任务调度)
│  ├─ 审查代码 → Skill 4 (代码审查)
│  └─ 提交代码/更新文档 → Skill 6 (文档系统)
│
├─ 🐛 质量保证阶段
│  ├─ 代码报错了 → Skill 7 (调试诊断)
│  ├─ 深度修复Bug → Skill 9 (BugHunter)
│  ├─ 检查功能完整度 → Skill 13 (功能审查)
│  └─ 检查项目健康 → Skill 12 (健康检查)
│
└─ 🔧 维护优化阶段
   ├─ 整理大文档 → Skill 2 (文档分段)
   └─ 清理项目 → Skill 11 (自动清理)
```

## 快捷指令速查

### 🎯 编排与调度
| 指令 | 功能 |
|------|------|
| `/plan` | 重新生成计划 |
| `/parallel` | 启动多任务调度 |
| `/next` | 继续下一阶段 |

### 💰 成本与监控
| 指令 | 功能 |
|------|------|
| `/cost` | 查看消耗 |
| `/compact` | 压缩上下文 |

### 📋 规划与文档
| 指令 | 功能 |
|------|------|
| `/memory` | 更新 memory.md |

### 🔍 代码质量
| 指令 | 功能 |
|------|------|
| `/bughunter` | 启动 BugHunter V2.0 |
| `/bughunter --high` | 仅检查高优先级 |
| `/bughunter --dim=<维度>` | 检查指定维度 |
| `/bughunter --scan-only` | 仅扫描不修复 |
| `/inspect` | 启动功能深度审查 |
| `/inspect --quick` | 快速检查 |
| `/inspect --full` | 完整检查 |
