## 账号说明

### 角色权限

- **ADMIN** - 系统管理员：拥有所有权限，可管理用户和系统配置
- **USER** - 普通用户：可使用测试平台的核心功能
- **GUEST** - 访客用户：仅有查看权限，无法创建或修改数据

### 账号状态

- **活跃** - 账号正常使用
- **禁用** - 账号已被禁用，无法登录

## 快速登录

访问登录页面：[http://localhost:3000/login](http://localhost:3000/login)

推荐使用以下账号快速体验：

1. **管理员体验** - 使用 `admin@example.com` / `admin123`
2. **普通用户** - 使用 `demo@example.com` / `password123`
3. **测试专用** - 使用 `qa@example.com` / `qa123456`

## 创建新账号

如需创建新的测试账号，可使用以下方式：

### 方式一：通过注册页面
访问 [http://localhost:3000/register](http://localhost:3000/register) 自主注册

### 方式二：运行脚本创建
```bash
cd ai-test-platform/my-app
node scripts/create-admin.js
```

### 方式三：管理员邀请
使用管理员账号登录后，访问设置页面邀请新用户
