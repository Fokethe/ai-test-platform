# 前端大重构计划 v1.0

## 一、现状问题诊断

### 1.1 导航结构问题
| 问题 | 描述 | 影响 |
|------|------|------|
| 功能重复 | `/ai-generate` 独立页面与 `/tests?tab=ai` 重复 | 用户困惑 |
| 层级过深 | 侧边栏子菜单展开逻辑不一致 | 操作效率低 |
| 入口分散 | 设置出现在侧边栏和用户菜单两处 | 认知负担 |

### 1.2 工作流程断层
```
期望流程: 需求 → 用例 → 执行 → 报告 → 分析
当前状况:
  - 需求生成: /ai-generate/requirements
  - 用例管理: /tests (用例/套件/AI生成三Tab)
  - 执行管理: /runs (历史/定时任务)
  - 质量分析: /quality (问题/报告分散)
```
**核心问题**: 缺乏工作流引导，用户不知道下一步该去哪

### 1.3 信息架构混乱
- **Dashboard**: 仅展示统计，缺少"快速开始"入口
- **项目/工作空间/系统**: 三个概念边界模糊
- **知识库 vs 资产库**: 功能重叠，定位不清
- **详情页**: 大部分未完成 (Tests/[id], Runs/[id]等)

### 1.4 设计系统不一致
- 部分页面仍使用旧版组件
- 表单设计不统一
- 缺少空状态、加载状态、错误状态的统一处理

---

## 二、重构目标

### 2.1 核心目标
1. **简化导航**: 以工作流为核心重组导航结构
2. **引导清晰**: 每个页面明确下一步操作
3. **统一体验**: 全系统统一设计语言和交互模式
4. **提升效率**: 减少点击次数，常用操作一键触达

### 2.2 关键指标
| 指标 | 当前 | 目标 |
|------|------|------|
| 完成核心工作流点击数 | 8-10次 | ≤5次 |
| 导航层级深度 | 3级 | ≤2级 |
| 页面加载时间 | - | ≤2秒 |
| 用户完成首次测试流程时间 | - | ≤10分钟 |

### 3.3 设计系统优化

#### 3.3.1 统一组件规范
```typescript
// 页面结构规范
PageLayout {
  header: PageHeader {
    title: string
    description?: string
    actions: ActionButton[]
    breadcrumbs?: BreadcrumbItem[]
  }
  content: {
    filters?: FilterBar
    toolbar?: Toolbar
    main: ContentArea
    sidebar?: ContextSidebar
  }
}

// 统一空状态
EmptyState {
  icon: LucideIcon
  title: string
  description: string
  action?: {
    label: string
    onClick: () => void
  }
}

// 统一加载状态
LoadingState {
  type: 'skeleton' | 'spinner' | 'progress'
  count?: number  // skeleton数量
}
```

#### 3.3.2 新增交互组件
| 组件 | 用途 | 优先级 |
|------|------|--------|
| WorkflowStepper | 工作流步骤引导 | P0 |
| QuickActionPanel | 快速操作面板 | P0 |
| ContextHelp | 上下文帮助提示 | P1 |
| DataEmpty | 数据为空状态 | P0 |
| ErrorBoundary | 错误边界处理 | P0 |
| RealtimeStatus | 实时状态指示器 | P1 |

#### 3.3.3 状态流转设计
```
需求状态: 草稿 → 评审中 → 已批准 → 已实现 → 已测试
               ↓
            已拒绝

用例状态: 草稿 → 评审中 → 已激活 → 已弃用
               ↓
            已归档

执行状态: 排队中 → 运行中 → 成功/失败/取消
```

### 3.4 用户体验优化

#### 3.4.1 快捷操作
- **全局快捷键**: 
  - `Cmd/Ctrl + K` - 全局搜索
  - `Cmd/Ctrl + N` - 新建
  - `Cmd/Ctrl + /` - 帮助

- **智能推荐**: 
  - 根据当前页面推荐下一步操作
  - 基于历史行为的快捷入口

#### 3.4.2 引导系统
- **新手引导**: 首次使用的交互式引导
- **功能提示**: 新功能的上下文提示
- **空状态引导**: 无数据时的创建引导

## 六、风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 重构范围过大 | 进度延期 | 分Phase实施，先核心后辅助 |
| API不兼容 | 功能异常 | 保持旧API兼容，逐步迁移 |
| 用户不适应 | 体验下降 | 保留切换选项，渐进式更新 |
| 性能问题 | 加载慢 | 代码分割、懒加载优化 |
