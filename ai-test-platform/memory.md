## 🐛 调试经验库
================================================================================

### 构建问题

**问题**: Module not found @/hooks/use-toast
**场景**: 运行npm run build
**解决**: 重新创建hooks/use-toast.ts文件

**问题**: Prisma Client未生成
**场景**: 拉取新代码后启动失败
**解决**: 运行`npx prisma generate`

### 测试问题

**问题**: API测试缺少NextRequest/NextResponse
**场景**: Jest运行API路由测试
**解决**: 使用`node`环境+手动mock，创建API辅助函数

**问题**: 测试环境变量缺失
**场景**: CI/CD中测试失败
**解决**: 创建scripts/check-env.js检查必要变量

### 数据库问题

**问题**: 迁移冲突
**场景**: 多人同时修改schema
**解决**: 删除dev.db重新生成，或创建新迁移

### 类型问题

**问题**: TypeScript any类型泛滥
**场景**: BugHunter检测到类型安全问题
**解决**: 强制使用strict规则，定义明确interface

## 💡 最佳实践
================================================================================

### 测试
- 单元测试用`__tests__/xxx.test.ts`
- API测试用`__tests__/xxx.test.ts`放在api目录旁
- 复杂逻辑必须测试覆盖

### API开发
- 统一使用wrapApiHandler包装路由
- 使用safeParseJsonBody解析请求体
- 错误返回统一格式{error: string}

### 类型安全
- 禁止any，使用unknown+类型守卫
- 所有API返回定义interface
- 复杂类型用zod验证

### Git
- 功能分支开发
- PR前必须测试通过
- 大任务分批次提交

### AI开发
- 使用Chain-of-Thought提升推理能力
- 实现Self-Reflection自检机制
- RAG使用分层架构（缓存+索引+重排序）
- LangGraph编排复杂工作流
